# Motorix

**Riparo më shpejt. Faturo pa gabime. · Fix faster. Bill right.**

Motorix is a free Windows app for car repair garages: customers and vehicles, work orders, appointments, quotes,
invoices in MKD / EUR with VAT, payments and debts, parts and stock, reminders by WhatsApp / Viber, reports and
automatic backups, in English, Albanian and Macedonian.

This repository only hosts the installers and update files. Motorix updates itself from here.

## Install
1. Open [Releases](../../releases/latest) and download **`Motorix-win-Setup.exe`**.
2. Run it. Windows may show "Windows protected your PC / Unknown publisher" (the app is not code-signed):
   click **More info → Run anyway**.
3. Motorix installs for the current Windows user (no admin rights needed) and starts the first-run wizard.

Your data is kept in `Documents\Motorix` and is never touched by updates or by uninstalling.

Requirements: Windows 10 (22H2) or Windows 11, 64-bit, screen 1366×768 or larger.
